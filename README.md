Adds a "Copy to folder…" option to the context menu – copies a file or folder to a chosen folder without renaming it."
It is the simplest plugin possible; it works only on desktop. Do whatever you want with it.
I would love to see it natively implemented into Obsidian.


INSTALLATION:
1. Download from official plugins site or from Obsidian directly.
2. Activate plugin, you may need to restart Obsidian after it.
3. Enjoy
